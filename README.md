# PyCode Frontend

A static frontend mockup for an online Python coding IDE.

## Run locally

Open `index.html` in your browser.

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.

The current **Run** button is a frontend demo. It does not execute real Python. A Python backend/sandbox will be connected in the next stage.

## Files

- `index.html` — interface
- `style.css` — styling and responsive layout
- `script.js` — editor interactions, local saving, demo run output
